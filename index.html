Common questions

What is a stress-test script?
A controlled load generator to test weak points.
What's the difference between L4, L7, and Bypass?
L4 sits at the transport layer — TCP/UDP volumetric pressure. L7 sits at the application layer — HTTP/2, HTTP/3, JA3/JA4 fingerprinting. Bypasses are heuristic-aware.
What languages are the scripts written in?
Mostly Rust (RS-prefixed) and C (C-prefixed). The language is shown as a small badge next to each script in the catalog.
